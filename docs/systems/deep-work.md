# Deep work, without heroics

Deep work is not a personality type. It is a **scheduled condition**: one task, no
inputs, a defined end. This note is my working version, not a manifesto.

## The unit

**One 90-minute block.** Not four hours, not "until it's done".

- 90 minutes matches a natural ultradian cycle well enough for most people.
- It is long enough for real progress and short enough to protect.
- Two blocks a day is a serious practice. Three is a lifestyle that most people cannot sustain with a job.

## The ritual (5 minutes before)

1. **Pick one output** for the block. A document, a decision, a section — not "work on the project".
2. **Write the first action.** The literal first click.
3. **Close everything else.** Tab groups closed, notifications off, phone in another room.
4. **Set the clock.** Visible countdown, not a stopwatch you have to check.
5. **Write down the distraction** when it arrives — one line, then back to work.

That last step is the highest-leverage habit in this note. Most people don't
resist distractions badly; they *follow* them. Writing the distraction down
acknowledges it and ends it.

## The distraction log

Keep a page per block:

```
09:00 start — output: section 2 draft
09:14 — wanted to check email (wrote it down)
09:31 — thought about the dentist, noted
10:30 end — drafted 700 words, one open question
```

After a week you have data instead of a vague feeling of being scattered. The
usual finding: the same two or three triggers fire repeatedly, and they are
fixable with environment changes.

## Scheduling it honestly

| Situation | Realistic plan |
| --- | --- |
| Job with meetings | One 90-min block before the first meeting |
| Shared office / kids | Two 45-min blocks with headphones |
| Variable energy | Block when you are sharpest, not when it is convenient |
| Chronically interrupted | Escape the building; a library beats willpower |

:::tip[Defend the start, not the end]

Almost every failed deep-work attempt dies in the first ten minutes. Protect the
entry ritual aggressively and the block largely runs itself.

:::

## Shutdown ritual

Ending work badly is why evenings feel like a continuation of work.

- Write the **next action** for the project (so tomorrow doesn't start with orientation).
- Capture every open loop in one place.
- Close all work windows and say a version of "done for today" — out loud, if it helps.
- Do not check work email one last time "just in case". That is how the evening gets colonized.

## Measuring

Count **blocks completed**, not hours worked. Hours expand to fill anxiety;
blocks have edges.

If a week has zero blocks, the cause is almost always one of:

1. No protected calendar entry (most common).
2. Unclear next action, so starting feels expensive.
3. Sleep debt, so attention won't hold.
4. No single output, so the block becomes email with extra steps.
