# Reading & notes

The failure mode of note-taking is a beautiful archive nobody reads. Notes are
not a record of what you consumed; they are **tools for thinking** and inputs to
output. If a note never gets used, it's a souvenir.

## The pipeline

```
capture → distill → connect → create
```

| Stage | What happens | Where it lives |
| --- | --- | --- |
| **Capture** | A quote, a claim, a question — with the source | Inbox, one line each |
| **Distill** | Rewrite in your own words; keep the one sentence that matters | The note |
| **Connect** | Link to a note you already have, or a project | Links |
| **Create** | Use it in an essay, decision, or experiment | Output |

Most people live permanently in *capture*. The value is downstream.

## Reading, in two modes

**Survey mode** — deciding whether the book deserves your time.

1. Read the table of contents, the intro, and the conclusion.
2. Read one chapter in the middle.
3. Decide: read properly, skim for one idea, or abandon.

**Study mode** — for the rare book that deserves it.

1. Read a chapter with a pen.
2. Close it and write what you remember.
3. Write the one idea you'd tell a friend, in your own words.
4. Add a link to a related note.

:::tip[Abandon books freely]

A book you're 40 pages into and avoiding is not a commitment, it is a tax. The
sunk cost is the time already spent; the remaining cost is all future time.

:::

## Note formats that stay useful

### The literature note

```markdown
## <Book / article> — <author>

**The claim:** one sentence.
**Why it matters:** one sentence.
**Where I disagree / where it breaks:** one sentence.
**Use it for:** the project or habit this changes.
**Source:** page / link
```

Short on purpose. If you can't fill in "where it breaks", you haven't thought
about it yet.

### The permanent note

One idea, one note, in your own words, linked to at least one other note. These
are the building blocks of essays. Keep them small enough to reread in a minute.

### The book index (per book)

A single page with the five ideas worth keeping. Future-you will not reread the
book; future-you will read this page.

## A weekly pass

During the [weekly review](../systems/weekly-review), spend five minutes:

- Inbox to zero: every capture either becomes a note, gets linked, or is deleted.
- Add one link between two notes that belong together.
- Move one note into an actual output — a checklist, an essay, a decision.

## What not to do

- **Don't highlight and call it a note.** Highlighting is a bookmark, not thinking.
- **Don't build an elaborate taxonomy first.** Folders should be boring; links do the work.
- **Don't copy the whole chapter.** If it's that good, quote one paragraph and write three sentences about it.
- **Don't read only inputs.** Every week, produce something small.
