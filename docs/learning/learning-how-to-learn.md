# Learning how to learn

Most studying is re-reading, highlighting, and feeling familiar. Feeling familiar
is the trap: it is a signal of **recognition**, not recall. The exam, the
conversation, the real project asks for recall.

## The techniques that work

| Technique | What it is | Why it works |
| --- | --- | --- |
| **Retrieval practice** | Close the book and write what you remember | Forces reconstruction instead of recognition |
| **Spaced repetition** | Revisit at increasing intervals | Counteracts forgetting at the moment it matters |
| **Interleaving** | Mix problem types instead of blocking | Teaches you to choose a method, not just apply one |
| **Elaboration** | Explain why, and connect to what you know | Builds a web of retrieval cues |
| **Deliberate practice** | Work at the edge of ability with feedback | Turns repetition into improvement |

Highlighting is not on the list. It's fine as a first pass, but it is not learning
by itself.

## The Feynman loop

1. Pick the concept.
2. Explain it in plain language, as if to a smart beginner. Out loud or on paper.
3. Find the exact sentence where you get vague, hand-wavy, or suddenly quiet.
4. Go back to the source for just that gap.
5. Simplify again, ideally with an analogy.

The vague sentence is the whole exercise. That is where the understanding isn't.

## Learn by building

Courses create the illusion of progress because the path is pre-decided. Projects
create real progress because they generate questions you can't avoid.

- **Pick a project with a visible output** — a small app, an essay, a talk, a repair.
- **Define "done"** in one sentence.
- **Learn only what the project demands.** Let scarcity choose the curriculum.
- **Ship it badly, then improve one thing.**

This is why tutorials feel productive and leave nothing behind: you never had to
make a decision.

## Study sessions that hold up

A 50-minute session that beats a three-hour passive one:

```
5 min   — recall yesterday's material from memory (blank page)
25 min  — new material, one source only, notes in your own words
10 min  — practice problems / write a summary with the source closed
5 min   — write the three questions you can't answer yet
5 min   — schedule the next review (tomorrow, then in 3 days, then in a week)
```

## Where to spend attention

The study loop, in order:

1. **Confusion** — notice what you don't understand.
2. **One source** — resist the urge to open five tabs.
3. **Retrieve from memory** — close the source and write it down.
4. **Find the gap** — compare what you wrote to what's true.
5. **Explain it simply** — analogy, plain language, no jargon.
6. **Use it in a project** — a decision, an artefact, a working thing.

Then back to confusion, because there is always more of it. The loop is
deliberately small. Breadth comes later, once the core holds.

## Signs you are actually learning

- You can explain it without notes, including the parts you'd rather skip.
- You can predict what happens in a new example.
- You notice when a source is wrong or oversimplified.
- You can debug your own misunderstanding instead of re-reading until it feels better.
