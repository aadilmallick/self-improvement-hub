# Checklists

Checklists are for the moments when you don't want to think, decide, or
negotiate. Run the list. That's all.

## Daily minimum

The non-negotiable floor. Most days should exceed this; no day should miss it.

- [ ] Made the bed / cleared one surface
- [ ] Ten minutes outside, daylight on the face
- [ ] One deep work block (or the minimum version)
- [ ] Moved the body for ten minutes
- [ ] Phone did not enter the first and last 30 minutes of the day
- [ ] Wrote one line in the log

## Focus session

Before the block:

- [ ] One output written down
- [ ] First action written down
- [ ] Phone in another room
- [ ] Notifications off, tabs closed
- [ ] Timer visible
- [ ] Distraction log open

After the block:

- [ ] Next action recorded
- [ ] Distractions reviewed (same triggers as last time?)
- [ ] Session counted

Detail: [Deep work](../systems/deep-work).

## Phone hygiene

A ten-minute intervention. Do it once properly.

- [ ] Grayscale on
- [ ] Home screen reduced to one page of tools
- [ ] Social feeds moved two taps deep (or off the device)
- [ ] All non-human notifications off
- [ ] Charger moved out of the bedroom
- [ ] One blocker rule set for work hours
- [ ] First-30-minutes rule written down somewhere visible

Detail: [Environment design](../systems/environment-design).

## Dopamine reset

Choose 7, 14 or 30 days. Write the length down before starting.

- [ ] Define what's in scope (feeds? short video? games? news?)
- [ ] Remove the apps or log out
- [ ] Tell one person the end date
- [ ] Prepare a replacement for the bored/anxious moment (walk, book, cooking)
- [ ] Set a daily check-in reminder
- [ ] Plan the first night's alternative activity
- [ ] Write what you expect to feel on day 3, so day 3 doesn't surprise you

Detail: [Focus & dopamine](../foundations/focus-and-dopamine).

## Sleep hygiene

Evening:

- [ ] Caffeine cutoff hit (8–10 hours before bed)
- [ ] Last substantial meal 2–3 hours before bed
- [ ] Lights dimmed after sunset
- [ ] Screens down 45 minutes before bed
- [ ] Phone charging outside the bedroom
- [ ] Room cool, dark, quiet
- [ ] Same wind-down sequence as last night

Morning:

- [ ] Same wake time (±30 min)
- [ ] Light outside within an hour
- [ ] No feed before the first 30 minutes

Detail: [Sleep is a skill](../health/sleep).

## Weekly review

- [ ] Calendar open for next week
- [ ] Three metrics pulled
- [ ] Inbox cleared to zero-ish
- [ ] Three questions answered in writing
- [ ] One commitment cut
- [ ] Priority + experiment + protected block chosen
- [ ] Closing the laptop at the 30-minute mark

Detail: [The weekly review](../systems/weekly-review).

## Quarterly reset

- [ ] Last quarter's retro read out loud
- [ ] One outcome chosen, observable finish line written
- [ ] Two leading behaviours chosen
- [ ] Recurring blocks on the calendar
- [ ] Kill criteria written
- [ ] One old commitment deleted
- [ ] Rest week scheduled

Detail: [Goals & quarters](../systems/goals-and-quarters).
