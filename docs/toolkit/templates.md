# Templates

Everything here is intentionally plain text. Put it in whatever app you already
use — Obsidian, Notion, Apple Notes, a paper notebook. The tool is not the system.

## Experiment card

One card per experiment. Two weeks. One variable.

```markdown
## Experiment: ____

**Start / end:** ____ → ____ (14 days)
**Hypothesis:** If I ____, then ____ will improve because ____.
**Identity it serves:** I am someone who ____
**Doing what, exactly:** ____ (behaviour, time, place)
**Metric:** ____ (a number I can check weekly)
**Minimum version:** ____ (for bad days)
**Obstacles & responses:**
- If ____, then ____
- If ____, then ____
**Week 1 result:**
**Week 2 result:**
**Verdict:** Keep / Adjust / Kill
**What I learned:**
```

Rules: one variable, a measurable metric, and a verdict date. An experiment with
no verdict is just a new habit you haven't admitted to.
