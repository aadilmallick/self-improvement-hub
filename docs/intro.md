# How this hub works

This is where I keep everything I know about getting better at being a person —
habits, attention, energy, learning, and the systems that hold it all together.

It is **not** a course and there is no finish line. It is a working notebook that
happens to be public, organized so I can find things again in six months.

:::tip[Read this first]

Most people read self-improvement content and change nothing. The fix is not more
content — it is a loop: **learn one idea → run one experiment → review weekly.**
That loop is the whole site. Everything else is reference material.

:::

## How to use the site

1. **Pick one note.** Not a category, not a book list. One page.
2. **Write down one sentence** you want to be true about your week because of it.
3. **Turn it into a 14-day experiment** using the [experiment card](./toolkit/templates#experiment-card).
4. **Put the [weekly review](./systems/weekly-review) in your calendar.** Same time every week, 30 minutes, non-negotiable.
5. **Come back to this hub on Sunday**, not every day. Daily reading is procrastination with better vocabulary.

If you only have ten minutes today, read [Focus & dopamine](./foundations/focus-and-dopamine)
and run the [phone hygiene checklist](./toolkit/checklists#phone-hygiene). It is
the highest-leverage change for most people, including me.

## Three rules

:::note[Rule 1 — One change at a time]

Two new habits introduced together means neither gets tracked, and both get
blamed when the week goes sideways. Sequence them.

:::

:::note[Rule 2 — Design for the bad week]

Every system here assumes you will be tired, busy, and uninterested at some point.
If a habit only works on a good day, it is not a habit — it is a mood.

:::

:::note[Rule 3 — Keep what survives]

This hub is a record of experiments, not commandments. When something stops
working, it gets retired, not defended. Notes stay because they still earn
their place.

:::
