"You don't need motivation, you need systems" is true and also useless, because
most systems are just motivation with a spreadsheet. A system that requires you
to feel good to run it isn't a system. It's a preference.

{/* truncate */}

## Three tests for a real system

**1. Does it survive a bad day?**

A system with only a full-size version is not a system, it's a best-case scenario.
Every recurring commitment here has a **minimum version** — ten minutes, one
page, one set. The minimum exists so the identity stays intact when the day falls
apart.

**2. Does it produce a decision?**

A system that produces information but no decision is a dashboard. The
[weekly review](/docs/systems/weekly-review) is thirty minutes because it ends in
three things: one priority, one experiment, one thing to cut. If it doesn't end
there, it's journaling.

**3. Does it have an owner?**

Goals without a calendar entry are wishes. If a behaviour doesn't have a time,
a place, and a trigger, it will lose every conflict it has with something that
does.

## The quiet part

Systems reduce the number of decisions, but they don't remove the cost of
decisions — they move it. Building the system is the expensive part; running it
is cheap. Which means the real work is front-loaded, and most people quit before
they reach the cheap part.

That's why I like the smallest possible version of everything. A system built in
an afternoon beats a system designed for three weeks, because the one built in an
afternoon actually gets used.

## What mine looks like now

- **Weekly:** the 30-minute review. Three numbers, three questions, one priority.
- **Daily:** one deep work block, one walk, phone away for the first and last 30 minutes.
- **Quarterly:** one outcome, two leading behaviours, kill criteria written in advance.
- **Always:** templates instead of blank pages, and a minimum version for every commitment.

That's it. No colour-coded dashboard, no second brain, no 5 a.m. routine. The
goal isn't an impressive system. The goal is one that is still running in
February.
